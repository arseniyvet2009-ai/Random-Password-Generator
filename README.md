# Random Password Generator

**Автор:** [Раковенко Ярослав]
**Дата:** Май 2026

## Описание

Приложение для генерации безопасных случайных паролей с графическим интерфейсом. Позволяет настраивать параметры генерации и сохранять историю созданных паролей.

**Основные возможности:**
* Настройка длины пароля (от 8 до 64 символов).
* Выбор типов символов для генерации: цифры, буквы (строчные и прописные), спецсимволы.
* Генерация случайного пароля по заданным параметрам.
* Копирование сгенерированного пароля в буфер обмена одним кликом.
* Сохранение истории всех сгенерированных паролей между запусками приложения.
* Просмотр истории паролей в удобной таблице с фильтрацией по параметрам.


**Целевая аудитория:**
* Пользователи, которым нужно создавать надёжные пароли для различных сервисов.
* Системные администраторы.
* Разработчики и тестировщики.
* Все, кто заботится о безопасности своих учётных записей.

## Как запустить приложение

**Требования:**
* Python 3.6 или выше.
* Стандартные библиотеки: `tkinter`, `random`, `string`, `json`, `os`, `datetime`.

**Запуск:**
1. Откройте терминал или командную строку.
2. Перейдите в директорию проекта: `cd path/to/RandomPasswordGenerator`.
3. Запустите приложение: `python main.py`.

## Примеры использования и тесты

### Тест 1: Базовая генерация пароля
1. Запустите приложение.
2. Убедитесь, что ползунок длины установлен на значение 12 (по умолчанию).
3. Проверьте, что отмечены чекбоксы «Цифры» и «Буквы», а «Спецсимволы» — не отмечен.
4. Нажмите кнопку **«Сгенерировать пароль»**.
5. Убедитесь, что в поле отображения появился пароль длиной 12 символов, состоящий из цифр и букв.
6. Проверьте, что запись о пароле появилась в таблице истории.


## Особенности реализации

* **Безопасность:** пароли генерируются с использованием модуля `random` Python.
* **Сохранение данных:** история паролей сохраняется в файле `password_history.json` в формате JSON.
* **Интуитивный интерфейс:** все элементы управления расположены логично и понятно.
* **Валидация:** проверка корректности настроек перед генерацией пароля.
* **Удобство использования:** возможность быстрого копирования пароля в буфер обмена.
* **Гибкость:** пользователь может настраивать параметры генерации под свои нужды.
